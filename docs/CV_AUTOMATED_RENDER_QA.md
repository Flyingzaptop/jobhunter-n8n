# Independent automated CV render QA

Enable `CV_AUTOMATED_RENDER_QA_ENABLED=true` and set `POPPLER_BIN_DIR` to the directory containing `pdftoppm.exe` (or `pdftoppm` on Linux). The continuous CV lane first completes the existing writer, entailment, deterministic claims, identity and PDF QA. Only a passing draft receives the additional independent audit. No new model inference occurs during this audit.

The audit rechecks current profile, latest analysis and source content hashes, exact document claims against the source map, deterministic factual guards and PDF bytes. PDF.js extracts actual text rectangles; every visible text rectangle must lie inside the paper, use at least a six-point text height and avoid substantial overlap. One or two nonempty pages are required, with visible identity/contact details and every authored claim. Poppler independently renders each full page to PNG and PPM. The proof records page dimensions, nonblank ink counts and hashes for each raster, PDF, document and source map. This is a deterministic layout check; it does not claim human judgment of style or aesthetics.

Successful registration retains all existing QA and records `reviewer: AUTOMATED_INDEPENDENT_RENDER_QA`, `method: PDFJS_TEXT_GEOMETRY_AND_INDEPENDENT_POPPLER_PNG_PPM`. A database transaction locks the source job and checks the latest analysis before inserting the approved `cv_versions` artifact. All bound file hashes are rechecked before registration. A failing, clipped, stale or unrenderable artifact remains unregistered. Manual PDF inspection remains available through the existing tool.
